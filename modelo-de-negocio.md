# Modelo de Negocio — Micro-Agencia Webs Locales
### Estrategia MRR-First: crecer rápido, cobrar recurrente

> Versión 1.0 — Mayo 2026

---

## La idea central

En lugar de vender webs como un proyecto único (cobra, entrega, adiós), el modelo funciona como una suscripción: el cliente paga poco o nada al principio y una cuota mensual fija que cubre todo. Tú ganas más a largo plazo, el cliente percibe menos riesgo, y el negocio se vuelve predecible y escalable.

Es el mismo modelo que Spotify, Shopify o cualquier SaaS — aplicado a webs para negocios locales.

## Estructura de Precios

### Plan único recomendado para empezar

| Concepto | Importe |
|---------|---------|
| **Setup inicial** | **199€** (pago único) |
| **Cuota mensual** | **89€/mes** |
| **Permanencia mínima** | **12 meses** |
| **Compromiso total año 1** | ~1.267€ |

El setup de 199€ no es para ganar dinero — es para filtrar a clientes que no son serios. Un negocio real que quiere una web no tiene problema en pagar 199€. Quien regatee ese importe te va a dar problemas todo el año.

### ¿Qué incluye la cuota de 89€/mes?

Todo lo que el cliente necesita para no pensar en su web:

- Hosting (Vercel + Cloudflare)
- Dominio (.es o .com)
- SSL / HTTPS
- Actualizaciones de contenido (hasta 2 cambios/mes vía WhatsApp)
- Mantenimiento técnico y actualizaciones
- Formularios de contacto operativos
- Integración WhatsApp activa
- Backups automáticos
- Soporte por WhatsApp en horario laboral
- Informe mensual básico de visitas

**Lo que NO incluye** (oportunidades de upsell):
- Cambios de diseño o nuevas secciones → 150-300€
- Sistema de reservas avanzado → 200€ setup + 20€/mes
- Carta digital / menú actualizable → 150€ setup + 15€/mes
- Google Ads / SEO activo → desde 200€/mes
- Sesión fotográfica → derivar a fotógrafo (comisión)

## Unit Economics (por cliente)

### Coste real de construir y mantener una web

| Concepto | Tiempo / Coste |
|---------|---------------|
| Construcción inicial (con plantilla) | 4-5 horas |
| Tu hora valorada | 40€/h |
| Coste implícito de construcción | ~180€ |
| Infraestructura mensual (Vercel, dominio, etc.) | ~3€/mes |
| Mantenimiento mensual real | 1-2 horas/mes |
| Coste mensual real (infra + tiempo) | ~50-60€/mes |

### Rentabilidad por cliente

| | Año 1 | Año 2 | Año 3 |
|-|-------|-------|-------|
| Ingresos | 199€ + (89€ × 12) = **1.267€** | 89€ × 12 = **1.068€** | **1.068€** |
| Costes | ~240€ construcción + ~600€ mantenimiento = **~840€** | ~600€ | ~600€ |
| **Beneficio neto** | **~427€** | **~468€** | **~468€** |
| **Margen** | ~34% | ~44% | ~44% |

A partir del año 2, el margen sube porque ya no hay coste de construcción. Un cliente que aguanta 3 años genera ~1.363€ de beneficio neto total.

> El objetivo no es el margen por cliente — es el volumen. Con 50 clientes, el tiempo real de trabajo es manejable por una sola persona.

## Retención: cómo evitar que se vayan

La retención es lo que hace o rompe este modelo. Una churn rate del 5% mensual destruye el negocio. Objetivo: < 2% mensual (equivale a una vida media de cliente de 4+ años).

### Mecanismos de retención (sin ser agresivo)

**1. Contrato de permanencia de 12 meses**
Cláusula de penalización si se van antes: pagan los meses restantes al 50%. La mayoría no se van — solo tener el contrato reduce el churn psicológico.

**2. El dominio lo gestionas tú**
El dominio está registrado a nombre del cliente pero gestionado por ti. Si se van, les transfieres el dominio — pero tienen que pedirlo explícitamente. La inercia hace que el 80% no lo haga.

**3. Entrega valor real cada mes**
El "informe mensual" no tiene que ser complejo — una captura de Google Analytics con 3 datos clave y un WhatsApp de "Este mes tuviste 340 visitas, un 12% más que el mes pasado" genera una percepción de valor enorme con 10 minutos de trabajo.

**4. Hazlo imprescindible**
Si el cliente usa el sistema de reservas, el menú digital o el formulario de contacto activamente, dejar la web significa perder esa infraestructura. Cuantas más funcionalidades activas, más stickiness.

**5. Propón mejoras proactivamente**
Una vez al trimestre, manda una propuesta de mejora pequeña (nueva sección, cambio de diseño, integración). Aunque el 80% diga que no, el 20% dice que sí (upsell) y el 100% percibe que estás trabajando para ellos.

## Capacidad operativa: ¿cuántos clientes puede gestionar una persona?

| Actividad | Tiempo/cliente/mes |
|-----------|-------------------|
| Actualizaciones de contenido (2/mes) | 30 min |
| Soporte y consultas | 15 min |
| Monitorización y backups | 5 min (automatizado) |
| Informe mensual | 10 min |
| **Total** | **~60 min/cliente/mes** |

| Clientes | Horas/mes mantenimiento | Viable para |
|---------|------------------------|-------------|
| 20 | ~20h | Side project |
| 50 | ~50h | Dedicación parcial |
| 80 | ~80h | Jornada completa (con automatización) |
| 100+ | Necesitas apoyo | Contratar 1 persona de soporte |

La automatización (plantillas, Sanity, scripts de informe) reduce este tiempo. A 100 clientes, podrías tener a alguien haciendo el soporte por 1.000€/mes mientras tú te dedicas a ventas y arquitectura.

## Estrategia Comercial para Escalar Rápido

### Fase 1 — Primeros 10 clientes (meses 1-2)

**Objetivo:** validar el modelo y tener referencias reales.

- Busca en Google Maps negocios locales de tu ciudad (peluquerías primero)
- Filtra los que no tienen web, tienen una web horrible, o su web no carga en móvil
- Contacta por WhatsApp o en persona con un mensaje directo:

> *"Hola [nombre], soy [tu nombre]. Me dedico a crear webs para [peluquerías] en [ciudad]. Vi que vuestra web tiene [problema concreto]. Os hago una web nueva por 199€ y luego 89€/mes todo incluido. ¿Os puedo enviar un ejemplo de cómo quedaría?"*

- Ofrece el primer cliente **gratis o a 49€** a cambio de una reseña en Google y poder usar su web como demo.
- Objetivo: 10 clientes en 2 meses.

### Fase 2 — Escalar a 50 clientes (meses 3-6)

- Con 2-3 demos reales puedes hacer demos en frío mucho más efectivas
- Sistematizar el outreach: 20 mensajes/día en Google Maps, 3-5 respuestas, 1-2 reuniones, 0.5-1 cierre
- Crear un vídeo de 60 segundos con la demo para enviar por WhatsApp
- Pedir referidos activamente: "¿Conoces algún otro negocio que pueda necesitar esto?"

### Fase 3 — Escalar a 100+ clientes (meses 7-12)

- Contratar a alguien para el outreach (a comisión: 50-100€ por cliente cerrado)
- Google Ads local: "web para peluquerías [ciudad]" — bajo coste, alta intención
- SEO del propio sitio de la agencia
- Partnerships con distribuidores de TPV, gestores de redes sociales, contables

## Posicionamiento y Mensaje de Venta

### Lo que NO debes decir:
*"Te hago una web bonita y moderna con diseño responsive..."*

### Lo que SÍ debes decir:
*"Te consigo más clientes desde el móvil. La web está lista en 5 días, sin complicaciones, y tú no tienes que tocar nada. 89€ al mes, todo incluido."*

El cliente local no compra tecnología — compra más clientes, menos llamadas perdidas y no tener que preocuparse de su presencia digital.

### Objeciones frecuentes y cómo responderlas

| Objeción | Respuesta |
|---------|----------|
| "Ya tengo web" | "¿Cuántos clientes nuevos te llegaron este mes por la web? Puedo mostrarte cómo mejorar eso." |
| "Es muy caro" | "Son 89€, menos de lo que gastas en café al mes. Y si en 3 meses no notas mejora, hablamos." |
| "Lo voy a pensar" | "Entiendo. ¿Puedo mandarte una demo de cómo quedaría vuestra web? Tarda 48 horas en hacerla y no os compromete a nada." |
| "Conozco a alguien que lo hace más barato" | "Seguro. La diferencia es que yo incluyo mantenimiento, actualizaciones y soporte. Con un freelance pagas cada vez que quieres cambiar algo." |
| "No sé si lo necesito" | "El 70% de las búsquedas locales se hacen desde el móvil. Si no estáis bien posicionados, esos clientes van a la competencia." |
